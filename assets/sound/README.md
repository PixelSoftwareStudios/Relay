# Sounds

Original sounds generated by this project with `generate.rs` (deterministic
additive synthesis, no samples or third-party material). Licensed Apache-2.0
like the rest of the repository.

Format: raw little-endian signed 16-bit mono PCM, 48 kHz, audible part only.
Loop periods (trailing silence) are defined in `crates/relay-audio/src/tones/`.

| File | Use |
|---|---|
| `ring.raw` | incoming-call ring (E5/A5 cadence, 2.0 s period) |
| `ringback.raw` | outgoing-call ringback (dual-tone double burst, 3.0 s period) |
| `call-end.raw` | one-shot falling blip |
| `connected.raw` | one-shot rising blip |

Regenerate from this directory: `rustc -O --edition 2024 generate.rs -o /tmp/gen && /tmp/gen`.
